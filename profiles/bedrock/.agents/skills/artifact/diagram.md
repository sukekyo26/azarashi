# 図の描き方

構成図・フロー・シーケンス・状態遷移などの図は inline SVG で座標を決めて描く。Mermaid・Graphviz・PlantUML などの自動配置ライブラリは使わない。箱を並べるだけで関係が伝わるものは HTML/CSS（grid・`cards`）で組む。

## 手順

1. 要素と関係を書き出し、流れの向き（左→右か上→下）を 1 つに決める。
2. 格子を決める。箱の大きさと間隔を固定値にし（例: 箱 160×56、列の間隔 72、行の間隔 40）、各要素を（列, 行）に割り当てて座標を計算する。線が箱を横切る配置になったら、ここで並べ替える。
3. 入れ子の枠（VPC・AZ・サブネット、システム境界など）は中身の外接矩形に余白 24 と見出しの高さを足した大きさにする。外側の枠から描く。
4. 描く順は 枠 → 線 → 箱 → 文字。線を箱の下に置く。
5. `<svg>` に `viewBox="0 0 W H"` と同じ値の `width` / `height` を付けて縮めない。`<div style="overflow-x: auto">` で包む。

## 見た目

- 色は `<style>` のクラスで `fill` / `stroke` に CSS 変数を当てる（雛形なら `--surface` `--line` `--fg` `--muted` `--accent` と `-soft` 系）。属性に直接色を書かない。ダークモードに追従させるため。
- 文字は `<text text-anchor="middle" dominant-baseline="central">`、13〜14px。箱の幅は文字幅（日本語 1 文字 ≈ 文字サイズ、英数字 ≈ 0.6 倍）に左右 16 以上を足して決める。収まらなければ `<tspan x="…" dy="1.2em">` で 2 行にする。
- 線は直角に折れる `<path d="M … H … V …">` にし、箱の中心ではなく辺で止める。矢印は `<marker orient="auto-start-reverse">` で付ける。
- 線のラベルは線の中点に置き、背景色の矩形を下に敷いて線と重ねない。
- 枠は破線か薄い塗り（`-soft`）で示し、見出しを枠の左上の内側に置く。
- 色に意味を持たせたときだけ凡例を付ける。強調は 1〜2 色に留める。

## 書き終えたら

座標を見直し、箱同士の重なり・文字のはみ出し・箱を横切る線・枠からはみ出す中身が無いことを確かめる。
