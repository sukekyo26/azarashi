# artifact スキル

エージェントが書いた単一 HTML ページや手元の HTML ファイルを、ローカルサーバー（`http://127.0.0.1:4317`）で表示・管理する。エージェントへの指示は `SKILL.md` にあり、ここには利用者向けの操作と仕組みを置く。

## 実行環境

- `artifacts.sh` は `bun` があれば bun、無ければ node で `artifacts.mjs` を動かす（bun の方が 1 回あたり約 20 ms 速い）。どちらも無ければ失敗する。
- 新しい slug を公開したときは `$BROWSER` → `wslview` → `xdg-open`（macOS は `open`）の順でブラウザを開く。開く手段が無い環境では URL を出すだけになる。
- 保存先は `~/.local/share/artifacts/<slug>/`（`ARTIFACTS_DIR` で変更）。リンクはここに `meta.json` だけを置く。ポートは `ARTIFACTS_PORT` で変更できる。
- サーバーは 127.0.0.1 だけで待ち受ける。コンテナの中で動かす場合は、ホストへのポート転送が必要。
- 127.0.0.1 は同じマシンの他のユーザーからも届き、ページの閲覧もリンクの登録もできてしまう。複数人で使うマシンでは動かさない。
- スキルを更新したときや bun を入れた・外したときは `artifacts.sh stop` してから `publish` する。動いているサーバーは起動したときのコードとランタイムのまま。

## ページの表示

- ページの URL（`/a/<slug>/`）は、管理画面へ戻る見出しバー（ダウンロードとページだけを開くボタン付き）の下に、ページを iframe で表示する。
- ページ本体は `/a/<slug>/?raw` で、HTML には何も差し込まない（再読み込み用のスクリプトだけ末尾に足す）。
- 同じ slug で公開し直すと、新しいタブは開かず、開いているタブが自動で再読み込みされる（1 秒程度で反映）。

## 管理画面

`http://127.0.0.1:4317/`

| 操作 | 方法 |
|:----|:----|
| 一覧 | 「アーティファクト」と「リンク」のタブに分かれ、生成元のプロジェクトで絞り込める。10・20・50・100 件ずつのページ送り（既定は 10 件）。更新順・作成順・タイトル順に並べ替えられる |
| お気に入り | 登録して絞り込める |
| 編集 | タイトル・URL 名・プロジェクト・説明をモーダルで編集する |
| 削除 | 削除ボタン。チェックした行をまとめて削除することもできる |
| ダウンロード | 保存したままの HTML（リンクはファイルのまま）を `<slug>.html` として保存する |
| リンクの追加 | 「リンク」タブの「リンクを追加」から絶対パスを入れて登録する。画面では slug を「URL 名」と呼び、入力した URL 名が別のファイルで使われていれば上書きせずに断る |

## リンクの詳細

- 登録するのはパスだけで、リクエストのたびにファイルを読む。ファイルを保存すれば開いているタブが再読み込みされる。本文だけの HTML は配信時に雛形で包む。
- 相対参照の CSS・JS・画像などは、ファイルのあるディレクトリの配下から配信する。配下から外へ出る参照（`..`・外を指す symlink）と、ドットで始まるパス（`.git` など）は配信しない。
- ディレクトリ全体が配信対象になるので、登録できるのは `.html` / `.htm` だけで、`/` や `$HOME` 直下のファイルと、ホーム直下の隠しディレクトリ（`~/.ssh`・`~/.config` など）の中のファイルは登録できない（リポジトリ内の `.agents` などは登録できる）。
- symlink は登録時に実体のパスへ解決して検査・記録し、後で実体が変わったら（symlink に差し替えられた等）配信しない。
- タイトルは配信のたびにファイルから取る（`--title` を付ければ固定できる）。
- 生成元のプロジェクトは、実行した場所ではなくファイルのある場所から決める。
- slug を省くとファイル名（`index.html` ならディレクトリ名）になる。同じパスの登録があればそれを更新し、別のファイルが同じ名前を使っていれば `-2`・`-3` … を付けて新しく登録する。`--slug` を明示したときは CLI では上書きする。
- 保存したページとリンクで同じ slug は使えない。種類を変えるときは `rm` してから登録し直す。
